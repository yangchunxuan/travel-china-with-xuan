# Canonical boundary — One Hub or Multiple Bases in China?

Checked: 2026-09-01 (Asia/Shanghai)

## Primary job to be done

Given one candidate stop inside a China route, decide whether it should be:

1. a day trip with no local hotel night, either returning to the same room or passing forward with bags to the next confirmed base;
2. exactly one local hotel night, always classified as one overnight even when the traveller leaves the room for both evening and morning activities;
3. a true base that retains the same local room beyond one night and supports repeated local starts, several independent priorities or a substantial multi-block purpose;
4. removed because no distinct value survives the complete travel and hotel chain; or
5. kept as a provisional range while a named dynamic fact remains unknown.

This is the reusable route-architecture owner. It counts full hotel-door blocks, hotel handoffs, return exposure, early/late value and failure recovery. It does not implement a public score or calculator.
