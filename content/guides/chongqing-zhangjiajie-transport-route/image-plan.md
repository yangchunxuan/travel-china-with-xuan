## Processing geometry correction
The earlier note said to crop a 4032×2268 source to a height of 2520 pixels. That is impossible because 2520 exceeds the source height.

The current derivative uses an exact integer 16:10 crop of **3624 × 2265**: 204 pixels removed from each horizontal edge, one pixel from the top and two pixels from the bottom. It was then resized with Lanczos to 1600×1000 and encoded as WebP q82 method 6 in a fresh output container so EXIF/GPS was not carried into the website asset. This replaces the earlier letterboxed derivative without generating or extending any image content.
