## Hero composition guardrails

- Do not use one famous skyline to represent all of China.
- Do not create a montage that implies equal scale, distance or a recommended route.
- Do not use AI-generated documentary travel imagery.
- If an outline map is considered, central must verify the approved map/boundary standard first; the decision-flow hero avoids that risk.
- Text embedded in the hero needs three localized exports or must render as live HTML.

## Rights record fields

Every selected photograph needs: asset ID, exact location, photographer/owner, source URL, license or written permission, download date, permitted derivatives, required attribution, identifiable-person consent where applicable, and the section it evidences. A usable file without this record remains an asset gap.

## Responsive and accessibility QA

- Hero meaning survives at 320 px without relying on tiny labels.
- Decorative lines are hidden from assistive technology; the same flow appears in nearby text.
- Alt text describes the decision the image supports, not a generic “China travel” keyword.
- Captions distinguish illustrative context from live operational evidence.
