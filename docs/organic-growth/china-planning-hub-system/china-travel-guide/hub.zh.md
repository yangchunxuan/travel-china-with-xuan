# 中国旅行指南：先找到会改变整趟旅行的决定

中国太大，入境、交通、预约和住宿又彼此牵动，一篇有用的旅行指南不应是一张越来越长的景点清单。这里是全国导航起点：先识别你正在做哪个决定，再打开负责该问题的专项指南，等下一个问题浮现时再回到这里。

第一次来中国，先写下四个事实：实际有多少晚、能使用哪些国际进出门户、最在意的地方，以及同行者中节奏最慢的人有什么需求。然后按照 **灵感 → 选择 → 验证 → 人工帮助** 向前走。入境规则、车次、景点门票和酒店条件都可能变动，对应的专项页会告诉你哪一项需要临行复核。

## 1. 先选对问题，再开始收集答案

很多规划失误，是因为把几个不同问题混成了一个。地方好看，不等于它适合这条路线；列车运行时间短，不等于整次转场快；房间页面看起来不错，不等于酒店是合适的基地。先找到最符合当前状态的一行。

| 你现在的情况 | 先去哪里 | 在那里决定什么 |
|---|---|---|
| “我还在找灵感。” | [探索中国](/zh/explore/) | 哪些地方或体验真正值得进入这趟旅行 |
| “我想先看懂现场。” | [中国文化与现场理解](/zh/culture/) | 哪篇历史、活态实践、饮食或艺术指南能解释这个地方 |
| “我已经有愿望清单。” | [规划行程](/zh/plan/) | 住几晚、城市角色、顺序、门户、住宿基地和节奏 |
| “我要先确定能否入境。” | [入境与实用指南](/zh/essentials/) | 哪条官方规则适用于护照、目的和路线 |
| “我在比较飞机、火车或接驳。” | [中国交通](/zh/transport/) | 完整的门到门移动，而不只是班次时长 |
| “我不知道住哪里。” | [住在哪里](/zh/stay/) | 先选能支撑每日行程的基地，再比较酒店 |
| “我的日期可能麻烦。” | [何时出发](/zh/when-to-go/) | 天气、公众假期或季节性开放是否改变方案 |
| “我要开始预订了。” | [中国实用指南](/zh/essentials/) | 官方责任方、实名信息、变更规则与失败处理 |

这样分流是有意的。Homeground 不会为“城市 × 月份 × 天数 × 人群”每一种组合制造新网址。只有当某个组合产生父页无法解决、而且有证据支撑的独立决定时，才值得拆出子页。

## 2. 在锁定路线前，先确定入境路径

入境是一道门槛，不是买完交通后随手扫过的一段话。必须把官方规则与护照、旅行目的、进出境点，以及途中每一次过境相对应。对一种国籍或一条航线成立的条件，不会自动适用于另一个人。Homeground 解释公开规则，但不判定个人资格，也不代办签证。

在[中国实用指南](/zh/essentials/)中找到对应的护照或过境 owner，先看来源复核日期，出发前再向国家移民管理局、负责的中国使领馆和承运人核实。只要关键一环仍有疑问，就不要急着锁死路线和不可退改的预订。

同一栏目还要处理抵达头几小时容易卡住的实用环节：支付、移动网络、预订实名与住宿登记。在这些没处理好之前，不要把稀缺的定时景点压在抵达日。[抵达日决策指南](/zh/guides/china-arrival-day-booked-anchor-or-flexible-block/)会说明何时只安排可替换活动更稳妥。

## 3. 给每个目的地一个明确任务

灵感只有在每个地方都有停留理由时，才会变成路线。打开[探索中国](/zh/explore/)，把候选地分成五种角色：

- **门户：**让国际抵达或离境顺利成立；
- **主锚：**有一项最高优先级体验，足以支撑几晚停留；
- **差异：**补充前面没有的风景、历史、饮食或节奏；
- **恢复基地：**减少移动，让旅行有一段慢下来；
- **可选延伸：**只在转场和换酒店后仍有真正可用时间时才保留。

两个作用重复的地方，是最先应考虑删掉的候选。名气大不会自动变成主锚，地图上相近也不代表轻松加入。先看目的地 Hub 中的街区、住宿基地和下一站逻辑；只有当城市已经证明值得留下，再进入单个景点页。

本页不复制城市行程。有明确地名的顺序问题，继续归[北京—西安—成都路线顺序](/zh/guides/beijing-xian-chengdu-route-order/)或[上海—苏州—杭州—南京路线顺序](/zh/guides/shanghai-suzhou-hangzhou-nanjing-route-order/)等精确 owner。

## 4. 把晚数变成路线，不要只排日期

当你已有日期或候选地，进入[中国行程与首次旅行 Hub](/zh/plan/)。先用晚数计算：七晚会跨过八个日历日，但不会自动产生八个完整游览日。抵达和离境时段、入境、车站进出、行李、酒店办理和疲劳，决定首尾两天还剩什么。

然后检查方向。从不同国际门户进出，可能减少回头路；完整方法归[开口航班与路线规划](/zh/guides/china-open-jaw-flights-route-planning/)。固定一个基地可能保护体力，而逐段换基地可能减少距离；这个选择归[放射式基地还是多基地](/zh/guides/china-hub-and-spoke-or-multi-base-route/)。

最后，用已发布的[《你的中国行程是不是太赶？》](/zh/guides/is-your-china-itinerary-too-rushed/)检查压力。这个 Hub 不运行自动路线计算器，不得承诺即时评分、暗中收集路线输入，也不得生成个人行程网址。

## 5. 计算两个酒店房门之间的完整移动

时刻表只是转场的一个部分。路线还要容纳收拾、退房、前往正确机场或车站、安检和等候、班次本身、抵达后的站内移动、最后一段接驳，以及下一家酒店办理。所以，一段很短的铁路也可能切碎大半天；而一段较长车程，若两端都简单，反而容易处理。

在[中国交通](/zh/transport/)中找精确车站、机场或城市对。第一次坐火车，先看[第一次坐中国高铁](/zh/guides/china-high-speed-train-first-time-guide/)。夜车看起来能“省一天”时，用[夜车还是白天高铁](/zh/guides/china-night-train-or-daytime-high-speed-rail/)把睡眠、洗漱、行李和抵达后状态一起算进去。某一段枢纽接驳特别麻烦时，[私人接送还是公共交通](/zh/guides/china-private-transfer-or-public-transport/)会比较行李、行动能力、时间风险和失败后果，而不是默认某一种方式总是更好。

Hub 不应抄录当前班次或价格。待预售开始或出发日临近时，核对精确日期、站名、承运人和购票渠道。

## 6. 先选基地，再选房间

住宿是路线基础设施。如果每天早上都要多穿过一次城市，“靠近地铁”实际对应错误出入口，或者深夜抵达依赖无人值守的入住流程，较低房价也可能很不划算。在[住在哪里](/zh/stay/)中按反复出现的日程选区域，然后才比较物业。

全国通用的检查可从[《在中国订酒店，离地铁多近才算方便？》](/zh/guides/china-hotel-near-metro/)开始。核对精确出入口、街面步行路线、电梯或台阶、深夜通行、路边到前台的完整链条、外国护照接待，以及酒店自己的书面确认。轮椅使用者要用[无障碍中国路线规划](/zh/guides/wheelchair-accessible-china-route-planning/)核验全链条；一个坡道不足以证明整趟旅行可达。

只有当换酒店能取消反复的长距离，或保护一段关键离境链条时，才值得。两个街区在地图上看起来很远，不构成充分理由。这项成本还包括重新打包、退房、寄存、接驳和再次安顿。

## 7. 把公众假期和固定预约放进同一张日历

某些日期会改变全国交通需求和景点压力。使用[中国公众假期旅行日历](/zh/guides/china-public-holidays-travel-calendar/)查看官方假日和调休工作日。如果下一年安排还没有发布，页面必须明确写“尚未发布”，不能外推日期，也不能自造拥挤指数。

接着列出所有硬约束：国际航班、具名列车、定时景点、演出、酒店取消截止时间，以及会改变路线的闭馆日。预约一旦错过会带来多大后果，它就需要多大的缓冲。如果它紧跟抵达或跨城转场，要问一句：把这段改为弹性模块，是不是更能保住全程？

购买景点产品时，[官方还是经销商门票](/zh/guides/official-or-reseller-china-tickets/)会帮你识别票务 owner，正确传递实名信息，区分“已提交申请”和“已确认”，并比较取消和退款条款。场馆当前官方通知仍然是运营事实的最终来源。

## 8. 让最不能快的同行者决定节奏

团队节奏不是取平均值。幼儿、长辈、轮椅使用者、需要管理疲劳的人，以及携带大量行李的旅客，可能需要不同的转场余量和恢复时段。不要把他们塞进同一套通用模板，而要进入对应的专项 owner：[带幼儿游中国](/zh/guides/china-itinerary-with-young-children/)、[带父母游中国](/zh/guides/china-itinerary-with-older-parents/)或[无障碍中国路线规划](/zh/guides/wheelchair-accessible-china-route-planning/)。

保留三种余量：

1. **操作余量：**用于班次出发、定时入场和最晚入馆前；
2. **恢复余量：**用于长途旅行、深夜抵达或高步行量之后；
3. **选择余量：**允许你删掉一个可选点，而不破坏已预订的连锁。

最后一晚应单独检查。[国际航班前一晚住哪里](/zh/guides/china-last-night-before-international-flight/)会同时权衡机场通达、早班风险和多留一个城市夜晚的价值。

## 9. 复核会变的事实，再选择下一步

出发前一周——以及每次发生重大时刻变更后——重新核对入境文件、精确航站楼与车站、预订姓名与护照号、景点状态、酒店确认、假期影响，以及最重要预订失败时的备用方案。当前运营事实用官方来源；Homeground 指南用来说明哪一个事实会改变决定。

路线通过检查，就继续自己规划。如果你已经有可用的逐日行程，但想请真人压力测试，可以比较 **Route Review**；有日期和优先级、但还没有可执行路线，比较 **Route Build**；需要把预订或当地协调纳入范围，讨论 **Full Trip Planning & Ground Support**。详细边界归[中国行程审核与路线规划](/zh/china-itinerary-review/)。

你也可以提交一份共享简报，包含日期或总晚数、人数、候选地、节奏或行动需求，以及大致预算。Homeground 规划师会人工阅读，确认合适的范围、价格或报价与交付时间；若继续，再另行发送付款说明。首次咨询不是免费私人行程，不会自动产生结果，也不代表付费工作已经开始。
