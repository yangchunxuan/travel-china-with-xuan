# 中国行程规划：第一次来华，怎样把路线排得走得通

第一次来中国，没有一条对所有人都最好的路线。真正有用的行程，必须同时容纳你的**酒店夜数、抵离时段、进出境门户、核心体验和实际旅行节奏**。先保护完整游览日，再判断每多一座城市是否真的带来不同体验。高铁很快，并不等于退房、去车站、候车、抵达和再次入住都消失了。

这页负责把愿望清单变成路线骨架，不会免费生成一份逐小时私人行程，也不会假设通用的7天、10天或14天模板适合每一班航班和每一组旅客。问题一旦变得具体，就进入相应的入境、交通、住宿、节假日、票务或城市顺序 owner。

## 先回答六个问题，不要先抄一串名城

决定顺序前，先写清六项输入：

1. **夜数：**在中国境内实际住多少个酒店夜，而不是把行程四舍五入成“约两周”。
2. **门户：**从哪个机场或口岸进入，从哪里离开。在比较航班时刻和总成本前，两端都可以保持候选状态。
3. **优先项：**选出三至四个“少了就不像这趟旅行”的体验。它们可以是地点、景观、饮食、博物馆或与人相处的时间，不必把十个地图标记都列为最高优先级。
4. **城市角色：**每个拟过夜城市能提供什么其他城市不能替代的作用。
5. **固定约束：**国际航班、实名定时票、闭馆日、公众假期、活动，以及难以改动的私人安排。
6. **节奏：**同行者实际上怎样应对早起、长距离步行、大件行李、陌生车站和连续转场。

这个顺序可以避免一种常见失误：先选五个城市、买一张机票，最后才发现有效日不够，或者没有理由却必须回到原入境城市。

如果入境资格还没确认，只把路线做到“候选骨架”即可。先进入[中国旅行实用信息](/zh/essentials/)，并核对与护照、来华目的和实际路线对应的官方来源。规划页不能替任何人判断个人入境资格。

## 把酒店夜数换算成真正可用的游览日

酒店夜数是比“几天游”更干净的起点，因为它会暴露抵达日、离境日和换城日。但酒店夜也不等于完整游览日。

给每个自然日做一行账：

| 日期类型 | 怎样才算 | 订票前如何使用 |
|---|---|---|
| 完整游览日 | 在同一城市醒来、在同一城市入睡，中间没有重大抵离链 | 留给最需要体力和完整时段的核心体验 |
| 碎片日 | 抵达、离境或较轻的转场后，只剩一段有限但可用的时间 | 只放靠近动线、可缩短、可替换的活动 |
| 转场主导日 | 退房、去枢纽、等候、跨城、抵达和入住占掉了最有用的时段 | 不要再把它包装成第二个完整游览日 |
| 保护缓冲 | 为高后果航班、固定预约或复杂衔接故意留空 | 风险消失以后再决定是否使用 |

深夜抵达可能增加一晚住宿，却不会增加一个游览日。早班离境会拿走最后一天的大部分时间。中午的列车也许在两端各留一小段，但会把注意力和体力切开，未必适合大型博物馆或远郊景观。

航班时刻未知时，保留范围：“四个完整日，条件好时可能五个”比直接采用乐观端点更诚实。[你的中国行程是不是太赶](/zh/guides/is-your-china-itinerary-too-rushed/)负责完整的节奏诊断。本页不运行自动路线计算器，也不会把未知假设包装成一个分数。

## 让每个过夜城市承担一个清楚的角色

把城市当作“任务角色”而不是“打卡奖杯”，行程才容易删改。

| 可能的角色 | 它回答什么问题 | 这座城市值得保留的证据 |
|---|---|---|
| 国际门户 | 从哪里进出能得到可用的航班时刻？ | 机场至酒店、酒店至机场的完整链条与路线相容 |
| 文化锚点 | 哪座城市值得为最重要兴趣保留多个完整日？ | 多个核心体验可以聚合，不需要天天跨城 |
| 景观反差 | 哪一站真正改变旅行的自然或城市环境？ | 有独立的过夜理由，而不只是另一个知名地名 |
| 区域连接点 | 哪个基地能让周边任务更顺？ | 从这里出发的日间往返或下一段路线确实连贯 |
| 恢复基地 | 在哪里能放慢、洗衣或吸收延误？ | 它减少压力，而不是再制造一次复杂换城 |

两座城市如果承担同一个角色，就在争抢同一批夜数。比较哪一座更符合已经写下的优先项，然后删除或留待下次。较短的第一次旅行，经常是在去掉一个作用薄弱的基地后才变好。

不要只凭总天数规定统一的城市上限。连续的铁路城市、轻装旅客，与需要飞机、山地门户和多个定时预约的组合，承担的路线成本不同。可从[天数与城市顺序集合](/zh/plan/trip-length-city-order/)进入已经批准的明确问题，但不要为每一种城市×日数排列新增页面。

## 每次换城都按酒店门到酒店门计算

列车或飞机的表定时长只是转场中段。决定连接前，把以下环节逐项写出来：

- 退房和处理行李；
- 从酒店到正确的车站或航站楼；
- 安检、证件核验、找路和合理的提前量；
- 表定旅程及其可能受到的延误影响；
- 从到达站台或行李厅到下一家酒店；
- 入住、吃饭，以及重新开始游览所需的体力。

这叫**转场负担**，不是承诺所有移动都会损失同样小时数。两端都较居中的高铁，有时比机场远离两家酒店的短途飞行更能保住一天。夜车可能省一晚房费，也可能削弱睡眠和次日能力。具体选择看[夜车还是白天高铁](/zh/guides/china-night-train-or-daytime-high-speed-rail/)，第一次执行铁路流程则看[中国高铁首次乘坐指南](/zh/guides/china-high-speed-train-first-time-guide/)。

同城换酒店也要计入成本。收拾、寄存、去第二家酒店和等待房间，会占掉原本想保护的灵活时间。使用[住宿选择 Hub](/zh/stay/)时，用抵达日、最重游览日和离境日三条门到门动线判断基地，不要只看地图上的地铁图标。

## 先选路线形状，再精排城市顺序

第一次旅行通常落在三种结构中：

| 结构 | 什么时候有用 | 必须测试的失败方式 |
|---|---|---|
| 开口程 | 路线自然向前推进，而且可以从不同门户进出 | 更高票价或不利时刻可能抵消少走回头路的收益 |
| 同一门户往返 | 某一城市的国际航班明显更强，或旅行集中在一个区域 | 最后的回程会不会吃掉一天，并让独立国内票衔接国际票 |
| 单基地往返或混合型 | 几个任务围绕稳定基地分布，只需一两次向前换城 | 反复日间往返会不会比换一次酒店更累 |

用[开口程航班与路线规划](/zh/guides/china-open-jaw-flights-route-planning/)比较完整的进出链；如果纠结是否保留一家酒店，看[单基地往返还是多基地](/zh/guides/china-hub-and-spoke-or-multi-base-route/)。地图上画得整齐不是理由，门到门移动更少、更可恢复才是。

国际离境前的最后一段必须单独保护。国内段和长途国际票分开购买时，要先回答前一段延误或取消会怎样。[国际航班前一晚住哪里](/zh/guides/china-last-night-before-international-flight/)负责这项决定。

## 路线能承受以后，再放固定预约

固定预约会形成约束网络：一张景点票可能依赖正确的护照姓名，抵达时间依赖入境和行李，跨城出发又可能要求提早离开大型景区。一个过紧假设可以同时让三张预订变脆弱。

按以下顺序放入约束：

1. 国际抵达和离境；
2. 不能移动的私人日期或活动；
3. 稀缺、实名或定时的核心体验；
4. 跨城转场日；
5. 灵活的博物馆、街区、用餐和休息模块。

抵达日通常只适合可缩短、可移动或可放弃的活动。只有完整抵达链有足够余量，而且损失可以接受时，才考虑放稀缺定时项目。[抵达日订定时锚点还是保持灵活](/zh/guides/china-arrival-day-booked-anchor-or-flexible-block/)提供完整风险树。

不要把任何一周默认当作普通周。先看[中国公众假期与旅行日历](/zh/guides/china-public-holidays-travel-calendar/)；官方放假日期、调休工作日和场馆安排会改变交通、酒店和票务问题。再用[官方票还是转售票](/zh/guides/official-or-reseller-china-tickets/)判断具体景点需要怎样的购票渠道和证据。本 Hub 不承诺实时余票。

## 让路线适合同一趟旅行里的人

“快”和“慢”不是给人贴标签。把节奏翻译成可观察的路线条件：连续早起、步行暴露、搬运行李、夜间交通后的睡眠、用餐弹性，以及困难一天后有没有恢复时间。

同一批候选城市，对三组人会产生不同答案：

- **轻装、使用开口程的两人同行**可以接受几个铁路相连的基地，前提是每次移动都向前推进，固定预约与转场风险分开。
- **带幼儿或学龄儿童的家庭**也许保留同样的锚点，但减少换酒店、晚一点开始，并让晚间模块可取消。儿童特有的链条归[带孩子的中国行程](/zh/guides/china-itinerary-with-young-children/)负责。
- **使用轮椅或需要连续无障碍条件的旅客**必须核验整条链：车辆、车站、电梯、厕所、酒店房间、景点和备选。看到一个坡道不能证明整段可达，请用[轮椅无障碍中国路线规划](/zh/guides/wheelchair-accessible-china-route-planning/)。

老人不必然走得慢，年轻人也不必然能连续恢复。真正要问的是，两个困难早晨或一晚睡眠中断以后会发生什么。明确人群的约束留在各自 owner 中，不为每个年龄×天数组合生成模板。

## 按后果从高到低验证路线骨架

不要一次把所有层级都买掉。按不可替代程度验证：

1. **入境：**核对护照、目的、允许停留和实际路线对应的官方规则。
2. **门户：**比较国际航班，也比较两端完整的地面接驳。
3. **路线段：**确认每个城市对之间存在合理交通方式，购票前再核实准确车站或机场。
4. **酒店基地：**逐家确认位置、外宾接待、房间与无障碍需求、取消条款。
5. **固定优先项：**按实际日期查官方票务、闭馆、实名和假期规则。
6. **预算：**纳入跨城、当地接驳、门票、换酒店和恢复方案，不只看票面价；完整框架看[中国旅行要花多少钱](/zh/guides/how-much-does-a-china-trip-cost/)。
7. **恢复：**提前决定哪些可移动、哪些先删除，以及哪一段离境连接必须保护。

车站、机场和城市对执行问题进入[中国交通 Hub](/zh/transport/)。任何付款前都要复核动态事实：班次、库存、票价、开放时间、放票规则、节假日安排和酒店政策都会变化。

## 修复过载路线时，先删除依赖关系

骨架不成立时，不要只把每座城市都压缩半天。先删除后果最大的依赖：

- 两个作用薄弱的城市带来两次换酒店，就删掉其中一个，把夜数还给主锚点。
- 路线明显回头，先比较开口程或反向排列，再考虑压缩游览。
- 抵达日放了固定景点，就把它移到完整日，抵达后只留街区、用餐或休息等可替换模块。
- 国内连接威胁国际离境，就提早进入离境门户或增加受保护的最后一晚。
- 活动、场馆或交通选项消失时，用同城替代活动保住“城市角色”，不要强行增加长距离换城。

好的恢复方案会明确“第一项删什么”。如果所有内容都声称不可放弃，那只是一个没有失败规则的愿望清单。

| 你已经有的材料 | 合适的下一步 |
|---|---|
