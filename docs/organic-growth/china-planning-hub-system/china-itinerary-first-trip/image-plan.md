## Hero design requirements

- Use five connected decision cards, not a geographic map with invented scale.
- Show a small “dynamic facts recheck” gate before booking.
- Show the human service path only after validation; do not display prices in the hero.
- Do not display a score, overload percentage, green approval badge or calculator input.
- Provide HTML text equivalents for every relationship; the image must not carry essential information alone.

A file already present in the repository is not, by itself, proof that it can be repurposed outside the recorded Homeground use.
