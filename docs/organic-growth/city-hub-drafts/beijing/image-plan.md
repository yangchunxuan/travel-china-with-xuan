# Beijing Destination Hub — image plan

**Image-policy result:** use traceable documentary photographs plus one original editorial diagram. Do not use AI-generated documentary tourism photography. Do not publish an image until its source page, creator, licence, crop and attribution have been retained in the implementation record.

**Licence and source-page review date:** 2026-08-15

## Publication verification checklist

Before any asset enters an implementation PR, the central editor must:

1. reopen the Commons source page and confirm that the licence has not been corrected, disputed or replaced;
2. retain creator, source-page URL, licence URL and modification note in the asset record;
3. download the original file from the source page, not a search-engine thumbnail;
4. verify that the crop still depicts the named place accurately;
5. attach locale-appropriate alt text and a caption that explains a planning relationship rather than merely restating the image;
6. place attribution where the licence requires it;
7. reject any AI-generated replacement that appears to document a real Beijing location.
