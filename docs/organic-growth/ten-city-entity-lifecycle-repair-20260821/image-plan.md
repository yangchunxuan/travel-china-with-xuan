# Ten-city image plan and rights gate

Checked: 2026-08-21. This document separates production assets from candidates. A candidate URL, category page or visually plausible photograph is not an asset until the exact file, author, capture date, licence/permission basis, crop, derivative terms and checksums are recorded.

## Uniform release rule

Each public Hub needs:

- one real, accurately located Hero that explains the city's spatial task;
- at least two explanatory place photographs for an established Hub, and four to six for a new Hub whose geography is otherwise easy to confuse;
- an optional original, non-scale diagram for relationships that photography cannot show;
- EN/ZH/KO alt and captions with the same factual limits;
- source and derivative SHA-256 records;
- mobile and desktop crop inspection;
- successful HTTP checks for every final image URL.

Reject AI documentary travel scenes, social-media screenshots, search thumbnails, an image from another city, a generic landscape with no verified location, an unlicensed film or performance still, and any photograph used to prove a timetable, opening state or accessibility condition that it cannot prove.

## Wrong-place and overclaim QA

Before release, assert all of the following:

- every file's place is one of the city/cluster nodes in `entity-network.json`;
- a photo used for an outer branch is captioned as an outer branch, not as downtown;
- Wuzhen is never presented as a Hangzhou attraction;
- Yangshuo and Longji are not captioned as Guilin neighbourhoods;
- Tianmen Mountain, Tianzi Mountain, the National Forest Park and Grand Canyon are not treated as one gate system;
- Futian Railway Station, Futian Port, Shenzhen Railway Station and Luohu Port are not interchanged;
- local-library permission is described as Homeground-project use, not an independently verified transferable photographer licence;
- current operating claims remain text facts with current official sources rather than inferences from photographs.
