# Image authority and rights gates

Checked: 2026-08-20

## Non-negotiable record

Every used or requested image records: exact object and city; creator; original file page; capture date when supplied; licence and attribution wording; original dimensions; crop/derivative status; identifiable people; and the claim the image cannot prove.

- No AI documentary imagery.
- No film, television, performance or modern-translation screenshots.
- No generic “ancient China” photograph standing in for a named site.
- No unidentified person close-up. Crowd images require a privacy and editorial-rights review.
- A façade cannot prove the age of an interior; a reconstruction cannot illustrate surviving original fabric; an exhibition label cannot be cropped away when it supplies the identity.
- Wikimedia Commons is an asset host, not factual authority. Identity is cross-checked against the museum/property map or official description.

## Body-image request pattern

Each package requests four to six explanatory photographs: an orientation view, a named original/surviving component, a clearly labelled reconstruction or modern insertion where relevant, one evidence-bearing object/label, and one route/threshold detail. Archive and object photography must additionally clear collection reproduction terms. Missing explanatory images remain documented asset gaps; they are never filled with a merely picturesque substitute.
