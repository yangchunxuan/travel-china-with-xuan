# Ten-city stay matrix

Reviewed: 2026-08-20

Baseline: `origin/main` `ef189874`

This is a decision matrix, not a directory of bookable hotels. Area names are
stable orientation anchors; every actual property, route, room and flight must
be rechecked for the traveller's dates. “First-trip default” means a useful
starting hypothesis, not a universal best area.

## Shared decision order

Every Hub, owner, FAQ or human handoff should preserve this order:

1. Confirm city, dates and the exact airport/station/attraction entrances already
   fixed by tickets or reservations.
2. Put those anchors in sight order; decide whether one base or one deliberate
   move reduces more friction.
3. Shortlist areas, then test the real property route: street, entrance, front
   desk, lift, room door and bathroom when relevant.
4. Confirm room/bed/connecting-room requirements, late arrival, staffed-desk
   expectations, luggage and payment/cancellation facts with the exact property.
5. Keep legal rules, platform display and current property confirmation as
   separate evidence.
6. Record a fallback area/property and a refusal, registration or inaccessible-
   route recovery plan before arrival.
