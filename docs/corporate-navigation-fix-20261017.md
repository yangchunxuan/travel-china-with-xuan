# 企业入口及首页显示修正

依据：`docs/corporate-travel-copy-review.md` 第 7 行，企业板块按公司旅行与团建、奖励旅游、小型会议与团队相聚三个目的组织。

- 八语页头均显示独立企业旅行一级栏目，桌面下拉列出三个目的；手机同级栏目展开后提供总览和三个目的入口。
- 入口指向现有 `/corporate-travel/` 及其三个真实锚点。企业正文仍为原分支的英文版本，其他语言的菜单说明明确标注英文页面；没有新增未翻译的本地化 URL 或 hreflang。
- 企业入口移出 Services 菜单和服务总页。保留已有个人旅行服务、产品价格、行程、套餐、人数和询价行为。
- 西语、法语一级栏目使用简短的 Empresas / Entreprises，下拉保留完整用途说明。
- 首屏标题及辅助内容在入场动画开始时保持完整不透明度，保留轻微位移。窄屏轮播退出等待与 CSS 的 260ms 淡出一致，原两秒轮播周期保持不变。
- 所有导出页头的独立企业入口、三类目的顺序、手机总览和服务菜单分离加入正式构建检查。

性能边界：在同一台 Mac 的 Chrome 中，单次普通刷新首次有意义绘制约 0.37 秒，禁用缓存刷新约 0.85 秒；这是本机观察，不能代表其他地区、设备或 LCP。未复现持续卡住，也未据此归因服务器或 CDN。

验收包括八语言、1180/1280/1440 桌面宽度、320/390 手机宽度，实际分类锚点跳转、菜单关闭与键盘焦点，以及独立截图复核。原企业内容的酒店、价格和供应确认边界保持原样。
