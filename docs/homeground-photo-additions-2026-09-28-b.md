# Homeground product photo additions B — 2026-09-28

This batch adds 11 real photographs for specific itinerary days. These files are prepared only; the route media in TypeScript is wired separately. Every source is a Wikimedia Commons **File page**, and the license below refers to the photograph itself, not Commons site text. All 11 downloads were the original files from `upload.wikimedia.org` (no Wikimedia thumbnail fallback was needed). Source SHA-256 values refer to the downloaded JPEGs; output SHA-256 values refer to the derived WebP files.

Processing: EXIF orientation was applied, the source was cropped to a 16:10 rectangle using the pixel bounds listed below, then resized to 1600 × 1000 with Lanczos and saved as WebP at quality 86. No scenery or objects were generated or redrawn. If using a CC BY or CC BY-SA image publicly, display the photographer's name, the linked File page and linked license; mention this crop/resize. CC BY-SA derivatives must be shared under the same or a compatible license.
